# Akash Chaurasiya: Portfolio

A static portfolio website. No build step, no dependencies.

## Files

- `index.html`: the whole site (HTML, CSS and a little JavaScript)
- `resume.pdf`: the file behind the "Download resume" buttons

Keep both files in the same folder.

## Run locally

Double-click `index.html` to open it in your browser.

## Put it online for free

**Netlify (fastest, about one minute)**
1. Go to https://app.netlify.com/drop
2. Drag this whole folder onto the page.
3. You get a public link right away. You can rename it in Site settings.

**GitHub Pages**
1. Create a new repository named `AkashChaurasiya3055.github.io` on GitHub.
2. Upload `index.html` and `resume.pdf` to it.
3. Open Settings, then Pages, and choose the `main` branch as the source.
4. Your site will be live at https://akashchaurasiya3055.github.io

## Update your details

Open `index.html` in any code editor (VS Code works well) and edit the text.

- To update your resume, replace `resume.pdf` with the new file and keep the same name.
- To link each project to its own repository, find the "View on GitHub" links in the Projects section and change the `href` to the repository URL.
